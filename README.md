# Айгерім Жұманбек — педагог портфолиосы

Статикалық сайт. Ашылуы үшін `index.html` файлын пайдаланыңыз. «Марапаттар мен алғыстар» бөлімінде PDF құжаттарының бірінші беттері көрсетіледі; суретті бассаңыз, толық құжат ашылады.

## GitHub Pages арқылы жариялау

1. GitHub-та бос репозиторий жасаңыз.
2. Осы бумадағы барлық файлды репозиторий түбіріне жүктеңіз. `index.html` түбірде тұруы керек.
3. Репозиторийден **Settings → Pages** ашыңыз.
4. **Deploy from a branch** таңдаңыз, `main` және `/(root)` орнатып сақтаңыз.
5. GitHub Pages көрсеткен сайт сілтемесін ашыңыз.

Бұл бумада 23 PDF бар. «Еңбек кітапшасы» жеке мәліметтер болуы мүмкін болғандықтан, ашық нұсқаға енгізілмеді.
